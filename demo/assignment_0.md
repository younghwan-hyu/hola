## 명세: ps 사용자 프로그램

- 인자에 따라 프로세스 정보 출력:
  - 인자 없음: 모든 활성 프로세스의 정보 표시.
  - 인자 있음: 주어진 PID(들)와 일치하는 특정 프로세스(들)의 정보 표시.
- 출력 형식 (엄격함):
  - 첫 줄에 헤더 `pid,state,name` 출력.
  - 상태 문자열: `unused` / `used` / `sleep` / `runble` / `run` / `zombie`
  - 반드시 쉼표로 구분. 추가 공백, 탭, 장식 문자를 넣지 말 것. (예: `1,sleep,init`)
  - 이 정확한 형식에서 벗어나면 0점이 될 수 있음.

## 명세: ps 시스템 콜

- 역할: 커널의 프로세스 테이블을 순회하며 요청된 프로세스(들)의 상태를 찾아 콘솔에 직접 출력.
- 시그니처: `int ps(int pid);`
  - pid (int): 조회할 특정 프로세스의 PID. **pid가 0이면 모든 활성 프로세스의 상태를 표시해야 함.**
  - 반환값: 대상 프로세스(들)가 존재하고 성공적으로 출력되면 0, 지정한 프로세스가 존재하지 않으면 1.
- 힌트: kernel/proc.c의 **procdump()** 함수를 참고하면 구현에 도움이 됨.
