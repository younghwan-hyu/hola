## 실습 수업의 목표

- 기본적인 운영체제인 xv6를 분석하여 OS 아키텍처를 완전히 소화한다.
- 원본 xv6가 지원하지 않던 새로운 기능들을 직접 만든다.

## 과제/프로젝트 일정 (Course Projects Overview)

- Assignment (3주차): System call (시스템 콜)
- Project 1 (5주차): CPU Scheduling (CPU 스케줄링)
- Project 2 (9주차): Thread (스레드)
- Project 3 (13주차): Virtual Memory & File System (가상 메모리와 파일 시스템)
- 그 외 수업 중 진행하는 in-class hands-on lab들이 있음.

## 제출 및 채점 정책 (Submission & Grading Policies)

- 모든 랩은 GitHub Classroom을 통해 제출해야 함.
- 늦은 제출(late submission)은 허용되지만, 마감 후 3시간 단위(3-hour window)마다 최종 점수가 5%씩 감점됨.
